# Segurança — Tempodroid

## Versões suportadas

A versão atualmente mantida é a versão publicada mais recente no Google Play.

## Relato de vulnerabilidades

Não publique detalhes sensíveis de uma vulnerabilidade em uma issue pública antes de uma correção estar disponível.

Use o recurso **Security Advisories** do repositório GitHub quando disponível. Para problemas não sensíveis, use:

https://github.com/claudiobr74/Tempodroid/issues

## Princípios do projeto

- sem segredos de produção no repositório;
- HTTPS obrigatório para chamadas de rede;
- localização aproximada opcional;
- sem localização em segundo plano;
- backup de dados do aplicativo desativado;
- build de release validado com lint, testes e R8;
- dependências monitoradas pelo Dependabot.
